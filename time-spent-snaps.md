# [Задача про статусы снапчатов](https://datalemur.com/questions/time-spent-snaps)

Предположим, вам даны таблицы с информацией о пользователях Snapchat, включая их возраст и время, потраченное на отправку и открытие снапов, возрастными группами в привязке к id пользователя.

Напишите запрос, чтобы получить разбивку времени, потраченного на отправку по сравнению с открытием снапчатов, в виде процента от общего времени, потраченного на эти действия, с группировкой по возрастным группам. Округлите процентные значения до 2 знаков после запятой в итоговом выводе.

Есть два подхода к решению этой задачки: 

1) через CASE
2) через FILTER в оконной функции

+ отработка деления на ноль

## Через CASE

1) JOIN по user_id с таблицей с возрастными категориями,
2) Отфильтруем только нужные статусы (WHERE activity_type in (open, send)), 
3) Сразу будем считать по возрастным группам - закладываем группировку по возрастными категориями GROUP BY,
4) Просуммируем время на открытие по группе SUM(CASE WHEN status = 'open' THEN time_spent ELSE 0 END),
5) Просуммируем время на закрытие по группе (аналогично),
6) Посчитаем по представленной формуле 100.0 x (общее время открытия /общее время 2х статусов) и аналогично 100.0 x (общее время отправки /общее время 2х статусов)
7) Обернем в ROUND (,2) по условию задачи

100.0 - чтобы автоматом перевести во float
Обернем в NULLIF(sending_time + opening_time, 0)

## Через FILTER (оконная фукнция)

1) JOIN по user_id с таблицей с возрастными категориями,
2) Отфильтруем только нужные статусы (WHERE activity_type in (open, send)), 
3) Сразу будем считать по возрастным группам - закладываем группировку по возрастными категориями GROUP BY,
4) Просуммируем время на открытие по группе SUM(time_spent) FILTER (WHERE activity_type = 'open'), тут же поделим на SUM(время 2х статусов), умножим 100.0, завернем в ROUND (,2) 
5) Просуммируем время на закрытие по группе (аналогично).
